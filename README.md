# Bank Account Management System

A simple **Bank Account Management System** developed in **C programming** as a beginner-level project.

This project demonstrates the use of **structures, functions, file handling, loops, conditional statements, and menu-driven programming** in C.

##  Features

*  Create a new bank account
*  View all accounts
*  Search for an account
*  Deposit money
*  Withdraw money
*  Delete an account
*  Menu-driven interface
*  Store account information using file handling

##  Concepts Used

* C Programming
* Structures (`struct`)
* Functions
* File Handling
* `if-else` statements
* `switch` statements
* Loops
* User Input and Output
* Basic Data Validation

##  Account Details

Each account stores:

* Account Number
* Account Holder Name
* Account Balance

##  How It Works

The program displays a menu with different banking operations. The user can select an option and perform the required operation.

### Main Menu

```text
===== BANK ACCOUNT MANAGEMENT SYSTEM =====

1. Create Account
2. View Accounts
3. Search Account
4. Deposit Money
5. Withdraw Money
6. Delete Account
7. Exit
```

The account information is stored in a file so that the data can be accessed during different operations.

## How to Run

1. Download or clone this repository.
2. Open the C file in a C compiler or IDE.
3. Compile the program.
4. Run the program.
5. Select an option from the menu and follow the instructions.

You can also run the program using online C compilers such as OnlineGDB.
